# One-player ping pong game
It's a simple program made for the sake of learning SFML in a single day.

## Compiling:
### MacOS:
- Install homebrew (https://brew.sh/)
- Run ```brew install sfml``` in a terminal
- Run ```./build```

### Linux:
Use your package manager and run ```./build``` in a terminal window.

### Windows:
IDK, I don't use Windows. Installing this on the system is an assignment for the player.
